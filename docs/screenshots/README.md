# Native iPhone captures

These are actual iOS Simulator captures from the native SwiftUI app. They are not browser mockups or generated phone designs. The player uses original demonstration captions from `Kaptus/App/AppStore.swift`, so the images do not claim to show a real synchronized movie.

Captured on iPhone 17 Pro Simulator running iOS 26.2, built with Xcode 26.3 at `9bd303f`. The [successful verification run](https://github.com/desigrit/kaptus-ios/actions/runs/35718030052) produced all six images. [Capture provenance and image digests](evidence.json) identify the exact originals. See [verification](../VERIFICATION.md) for test coverage. The yellow bird is the approved Kaptus brand artwork; see [asset provenance](../brand/PROVENANCE.md).
