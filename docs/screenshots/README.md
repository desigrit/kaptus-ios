# Native iPhone captures

These are actual iOS Simulator captures from the native SwiftUI app. They are not browser mockups or generated phone designs. The player uses original demonstration captions from `Kaptus/App/AppStore.swift`, so the images do not claim to show a real synchronized movie.

Captured on iPhone 17 Pro Simulator running iOS 26.2, built with Xcode 26.3 at `faeabf9`, Kaptus 0.2.1 build 3. The [successful activation run](https://github.com/desigrit/kaptus-ios/actions/runs/36801226995) produced all six images on September 30, 2026 (October 1 UTC). Five images came from the native simctl capture pass. The landscape image is the unmodified XCUIScreen attachment from `KaptusUITests/testHomeSettingsAndSamplePlayer()`, including its original PNG orientation metadata.

[Capture provenance and image digests](evidence.json) identify the exact originals, including the landscape attachment filename. See [verification](../VERIFICATION.md) for test coverage. The yellow bird is the approved Kaptus brand artwork; see [asset provenance](../brand/PROVENANCE.md).
