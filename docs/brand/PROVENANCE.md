# Wordbird

Copied from the user-approved yellow Wordbird in [Kaptus for Android](https://github.com/desigrit/kaptus/tree/ee09e55fad19b1a4b214a8f2b0712b7edd475404/docs/brand). The bird uses the same #FFC857 accent and the same 3-unit rightward placement correction. The iOS app-icon export replaces the transparent corners and circular outer background with a full opaque #176B70 square. The artwork itself is unchanged. The system supplies the final icon mask.

The raster icon is a deterministic browser render of app-icon.svg, not a generated redesign. The in-app Wordbird PNG is the original approved Android asset. Original generation and revision history remain in the Android brand directory.
